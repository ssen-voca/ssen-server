# 학생이 수업에서 나가기 (이슈 #31)

학생은 참여 코드로 수업에 들어가거나(`POST /api/me/classroom`, #24) 다른 코드로 옮길 수만 있고 나갈 수는 없었다. 수업에서 나가는 API를 더한다.

## API

`DELETE /api/me/classroom` → **204**

- 학생 토큰만 쓸 수 있다(교사 403, 비로그인 401). `SecurityConfig`의 `/api/me/classroom` 규칙이 이미 이 경로를 학생 전용으로 둔다.
- 수업이 없는 학생이 불러도 204다(멱등). 여러 번 불러도 결과가 같다.
- 시도 제한을 쓰지 않는다(코드를 추측할 수 있는 경로가 아니다).

## 나가면

- `app_user.classroom_id`만 비운다. `/api/users/me`의 `classroom`은 `null`이 된다.
- 교사가 올린 수업 단어는 `/api/me/words`에서 보이지 않는다. 단어 자체와 다른 학생에게는 영향이 없다.
- 학생의 계정, **개인 단어**, **북마크 기록은 그대로다.** 수업 단어에 건 북마크는 볼 수 없게 될 뿐 지워지지 않아서, 같은 수업의 코드로 다시 들어오면 북마크도 다시 보인다(`/api/me/bookmarks`는 지금 볼 수 있는 단어의 북마크만 돌려준다).
